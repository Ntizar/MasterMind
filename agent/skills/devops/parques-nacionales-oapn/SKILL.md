# Parques Nacionales — Datos Geográficos OAPN

## Resumen

El **Organismo Autónomo Parques Nacionales (OAPN)** del Ministerio para la Transición Ecológica (MITECO) ofrece datos geográficos de la **Red de Parques Nacionales** españoles.

**Página oficial:** `https://www.miteco.gob.es/es/parques-nacionales-oapn/red-parques-nacionales/sig/sig-descargas.html`

**Visor SIG:** `https://sigred.oapn.es/VisorRedPPNN/`

**Formatos:** Shapefile (.shp), KMZ (Google Earth), WMS (servicios web), PDF (metadatos)

**Actualización:** Variable según capa (ver fechas en tabla)

## 16 Parques Nacionales de España

1. Aigüestortes i Estany de Sant Maurici (Cataluña)
2. Archipiélago de Cabrera (Baleares)
3. Caldera de Taburiente (Canarias)
4. Cabañeros (Castilla-La Mancha)
5. Doñana (Andalucía)
6. Islas Atlánticas de Galicia (Galicia)
7. Monfragüe (Extremadura)
8. Ordesa y Monte Perdido (Aragón)
9. Picos de Europa (Cantabria/Asturias/Castilla y León)
10. Sierra de Guadarrama (Madrid/Castilla y León)
11. Sierra de las Nieves (Andalucía)
12. Sierra Nevada (Andalucía)
13. Tablas de Daimiel (Castilla-La Mancha)
14. Timanfaya (Canarias)
15. plus espacios naturales periféricos

## Ejemplo WMS GetMap

```bash
# Mapa de límites de parques nacionales (ESP:3857)
curl -o parques.png "http://sigred.oapn.es/geoserverOAPN/LimitesParquesNacionalesZPP/wms?\
service=WMS&version=1.1.1&request=GetMap&\
layers=view_red_oapn_limite_pn&\
styles=&bbox=-1200000,4400000,500000,5300000&\
width=800&height=600&srs=EPSG:3857&format=image/png"

# Bounding box EPSG:4326 para España completa
# bbox=-12,35,5,44
```

## Uso para dashboard regional

Para un dashboard como DatoAsturias enfocado en Cantabria/Madrid:

1. **Parques nacionales en la zona:**
   - Cantabria: Picos de Europa (compartido con Asturias y Castilla y León)
   - Madrid: Sierra de Guadarrama (compartido con Castilla y León)

2. **Capas más útiles:**
   - Límites + ZPP para mostrar extensión del parque
   - Áreas de influencia socioeconómica para contexto territorial
   - Sistemas naturales para biodiversidad
   - Seguimiento de aves para indicador de salud ecológica

3. **Integración con Leaflet:**
   - Usar WMS para capas base
   - Usar shapefiles descargados para polígonos interactivos
   - Usar KMZ para Google Earth embed

## Pitfalls

- **WMS en HTTP (no HTTPS)** → `sigred.oapn.es` solo acepta HTTP. En HTTPS da error SSL.
- **Formatos RAR** → algunos shapefiles vienen en .rar, no .zip. Necesitas `unrar` o `7z`.
- **CRS** → los shapefiles usan EPSG:25830 (ETRS89 / UTM zone 30N) o EPSG:4326 (WGS84). Verificar al proyectar en Leaflet.
- **Actualización irregular** → cada capa tiene su propio calendario de actualización. No asumir que todo está al día.
- **WMS lento** → el servidor de OAPN puede ser lento. Implementar caché o preload.
- **Licencia** → datos de libre reutilización según Ley 19/2015 de transparencia.
