# Quality Gates Checklist — Educational HTML Nightly

## Gate 1: HTML válido
- [ ] `<!DOCTYPE html>` presente

## Gate 2: Ejercicios funcionales
- [ ] Al menos un `onclick=` presente
- [ ] Funciones JS definidas para cada tipo de ejercicio
