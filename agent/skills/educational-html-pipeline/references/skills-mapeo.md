# Mapeo Skills TD → Bloques del Curso

## Bloque 1: Normalización (5 temas)
- **Skill fuente:** `td-normalizacion`
- **Temas:** b01-01 a b01-05
- **Contenido:** Formatos ISO 216, tipos de línea ISO 128, escalas ISO 5455, rotulación UNE, cuadro de rotulación

## Bloque 2: Proyecciones (8 temas)
- **Skill fuente:** `td-proyecciones`
- **Temas:** b02-01 a b02-08
- **Contenido:** Proyección ortogonal, sistema 3 planos, vistas principales, correspondencia, abatimiento PH, 1º/3º diedro, representación piezas, vista auxiliar/parcial

## Bloque 3: Perspectivas (6 temas)
- **Skill fuente:** `td-perspectivas`
- **Temas:** b03-01 a b03-06
- **Contenido:** Isométrica (ejes, cubos, círculos), caballera, dimétrica, monométrica, resumen perspectivas

## Bloque 4: Diedrico — Punto, Recta, Plano (10 temas)
- **Skill fuente:** `td-diedrico-punto-recta-plano`
- **Temas:** b04-01 a b04-10
- **Contenido:** Punto, recta, plano, pertenencia, paralelismo, perpendicularidad, verdaderas magnitudes, cambio de plano, giro

## Bloque 5: Cortes y Secciones (6 temas)
- **Skill fuente:** `td-cortes-secciones`
- **Temas:** b05-01 a b05-06
- **Contenido:** Tipos de cortes, secciones, medios cortes, cortes escalonados

## Bloque 6: Acotación (5 temas)
- **Skill fuente:** `td-acotacion`
- **Temas:** b06-01 a b06-05
- **Contenido:** Principios, elementos, métodos, cotas en isométrica, normas UNE

## Bloque 7: Intersecciones y VM (6 temas)
- **Skill fuente:** `td-intersecciones-vm`
- **Temas:** b07-01 a b07-06
- **Contenido:** Intersección recta-plano, recta-recta, plano-plano, VM por cambio de plano

## Bloque 8: Abatimientos (4 temas)
- **Skill fuente:** `td-abatimientos-giros`
- **Temas:** b08-01 a b08-04
- **Contenido:** Abatimiento PH, PV, PL, giros, aplicaciones

## Bloque 9: Planos de Conjunto (3 temas)
- **Skill fuente:** `td-planos-conjunto`
- **Temas:** b09-01 a b09-03
- **Contenido:** Despiece, lista de piezas, vistas auxiliares, acotación final
