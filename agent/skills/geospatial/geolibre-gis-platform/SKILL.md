# GeoLibre — plataforma GIS ligera cloud-native

> ⚠️ Corrección 2026-09-05 (auditoría): stars ~7.2K y URL de demo actualizada. La API de rendimiento/webmap no es maplibre/duckdb crudo — consultar el README real antes de escribir el snippet.

**Repo:** `https://github.com/geo-libre/geolibre` (TypeScript, ~7.2K⭐). GIS open-source ligero, cloud-native (mapas vectoriales rápidos).

## When to Use

- Cuando pidas una **plataforma GIS ligera cloud-native** (visualizar/publicar mapas sin servidores pesados) open-source.

## Qué es

GeoLibre provee tiles/rendering de mapas vectoriales rápidos, self-hostable. No uses maplibre/duckdb a pelo como si fuera la API pública — verificar los endpoints/modulos reales del repo.

## Uso

- Seguir el README del repo (servicios, Docker, endpoints). Consultar la demo actualizada.

## Pitfalls

- **No** copiar un snippet maplibre/duckdb genérico como "API" de GeoLibre.
- Demo/URL la verificar en el repo (está desactualizada).

## Verificación

- Levantar el stack del repo y servir un mapa vectorial rápido.
