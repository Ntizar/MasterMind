# GTFS to Chart — Gráficos de Frecuencia GTFS

## Qué es

GTFS to Chart es una herramienta para generar visualizaciones de frecuencia de rutas de transporte:
- **Frequency charts** — gráficos de frecuencia por hora/día
- **Route visualization** — visualizar rutas en mapas
- **GTFS-based** — consume feeds GTFS directamente
- **Web-based** — visualización en navegador

## Instalación

```bash
git clone https://github.com/BlinkTagInc/gtfs-to-chart.git
cd gtfs-to-chart
npm install
```

## Casos de uso para David

- **Dashboard de transporte** — visualizar frecuencias en dashboards
- **GTFS analysis** — analizar patrones de frecuencia
- **Passenger planning** — ayudar usuarios a planificar viajes
- **Integration** — integrar con dashboards existentes

## Pitfalls

- Enfocado en visualización, no en routing
- Requiere feed GTFS válido
- No incluye análisis de datos — solo visualización
- Comunidad pequeña
