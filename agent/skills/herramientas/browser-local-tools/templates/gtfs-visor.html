# Template — Visor GTFS en HTML autocontenido ## Uso Copiar este HTML como base para cualquier visor de datos GTFS. Solo hay que: 1. Embeber JSZip inline (ver `scripts/embeber-jszip.sh`) 2. Ajustar coordenadas por defecto 3. Personalizar estilos CSS ## Estructura del visor - **Drag & drop** de ZIPs GTFS - **Parser CSV** nativo (soporta `,`, `;`, `\t`) - **Cálculo Haversine** para distancias - **Cruce de datos**: stops → trips → routes → agencies - **Filtrado por radio** configurable (50-2000m) - **Tarjetas expandibles** por ruta con info de empresa - **Barra de progreso** durante carga de ZIPs - **Coordenadas rápidas** predefinidas - **Botón GPS** para ubicación actual ## Datos GTFS procesados | Archivo | Qué se extrae | Uso | |---|---|---| | stops.txt | stop_id, stop_name, stop_lat, stop_lon | Paradas con coordenadas | | routes.txt | route_id, route_short_name, route_long_name, route_type | Rutas con tipo y nombre | | trips.txt | trip_id, route_id | Mapeo viaje → ruta | | stop_times.txt | stop_id, trip_id | Qué paradas usa cada viaje | | agencies.txt | agency_name | Nombre de la empresa | ## Librerías requeridas - **JSZip** (~97KB) — parseo de ZIPs GTFS - Embeber inline, NUNCA usar CDN en visores compartidos
