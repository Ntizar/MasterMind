# Filosofía de datos de David Antizar

## Principio fundamental

Los datos tienen dos clases: **libres** y **privados**. Cada una tiene reglas distintas.

## Datos libres

Los datos públicos son de todo el mundo. Impuestos, presupuestos, horarios, consumo energético, licencias, contratos.

**Regla: los datos libres, libres.**

Deben circular. Ser descargados, mezclados, analizados, compartidos, criticados. Sin barreras. Sin pedir permiso. Sin pagar.

Cualquier ciudadano puede descargar datos públicos, cruzarlos con otros datos, y descubrir patrones. Sin intermediarios. Sin permisos.

## Datos privados

Datos privados no son del dominio público. Historial médico, nóminas, datos fiscales concretos, expedientes.

**Regla: los datos privados se procesan en local.**

Se pueden usar. Se pueden procesar. Se pueden analizar. Pero **no salen de ahí**.

- No a APIs externas
- No a la nube
- No a proveedores de IA
- No a ningún sitio

Se procesan en la máquina. Se obtiene el resultado. Y punto.

No es un límite técnico. Es una decisión política. Una línea que no se cruza.

## No se necesita IA

Esto no requiere inteligencia artificial.

- Los datos libres se pueden usar con herramientas deterministas: scripts que parsean, cruzan, visualizan
- Los datos privados se procesan con las mismas herramientas, pero localmente
- Herramientas que funcionan siempre de la misma manera, auditable línea por línea

No necesitas un modelo que "aprenda". No necesitas un LLM. No necesitas nada de eso.

Necesitas datos bien organizados, herramientas simples, y la decisión política de no cruzar la línea entre lo público y lo privado.

## Filosofía de gestión de datos

1. **Los datos libres circulan.** Sin restricciones, sin intermediarios, sin barreras técnicas innecesarias.
2. **Los datos privados se procesan en local.** Sin salir. Sin excepciones. Sin "confiamos en el proveedor".
3. **No se necesita IA.** Herramientas deterministas y abiertas bastan para la gestión de datos.

## Contexto de uso

Esta filosofía se aplica a:

- Administración pública y gestión municipal
- Privacidad ciudadana
- Tecnología y software
- Cualquier contenido sobre datos que David escriba

Cuando David pide un post, artículo o contenido sobre tecnología, datos o administración, basar el contenido en esta filosofía.
