## Flujo de datos en el browser

```
1. main.js → DEMO.cargarDatos()  (Promise.all de 4 fetches)
2. Usuario selecciona punto → handleCalcular()
3. Para cada isócrona generada:
   a. Extraer coordenadas del GeoJSON
   b. DEMO.buscarCPsEnPoligono(coords) → CPs dentro del polígono
   c. DEMO.estadisticas(cps) → población, salario medio, precios
   d. DEMO.buscarParadasCercanas(lat, lng) → {paradas, lineas, resumen}
   e. DEMO.calcularCostePorMinuto(...) → coste real por minuto
   f. DEMO.calcularEscenariosTeletrabajo(...) → {base, escenarios[], ahorro}
   g. DEMO.calcularCosteCO2Empresa(co2kg) → {coste_ets, coste_reputacional}
   h. Almacenar en resultado
4. docx-report.js → secciones 3B-3F
```

## Cálculos clave

### Coste por minuto de desplazamiento
```javascript
calcularCostePorMinuto(minutosIda, salarioBruto, modo, distanciaKm) {
  irpf = tramoIRPF(salarioBruto)  // 15%-42%
  ss_trabajador = salarioBruto * 0.0635
  salario_neto = salarioBruto - irpf - ss_trabajador
  coste_mensual = switch(modo):
    coche: distancia*2*0.20*22 + parking + peajes
    metro: 54.60
    bus: 1.50*2*22
    bici: distancia*2*0.05*22
    andando: 0
  coste_por_minuto = coste_mensual / (minutosIda * 2 * 22)
  sueldo_neto_trasporte = salario_neto - coste_mensual*12
  pct_neto = (coste_mensual*12 / salario_neto) * 100
}
```

calcularCosteCO2Empresa(co2AnualKg, sector='general') {

## Pitfalls

1. **fetch() no funciona en Node.js** — Para tests, cargar JSON con fs.readFileSync().
2. **Salarios por provincia dan el mismo valor a todos los CPs** — Usar salarios-por-cp.json.
3. **IRPF estimado** — El informe debe indicar "IRPF estimado" explícitamente.
4. **Correlación alquiler→salario ~0.75** — Zonas universitarias/industriales pueden desviar.
5. **delegate_task timeout en datasets grandes** — Usar execute_code para datos algorítmicos.
