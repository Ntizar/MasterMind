# Awesome Transit — Recursos de Transporte Público

## Resumen

Catálogo masivo de recursos de transporte público — APIs, datasets, herramientas, estándares. 1.7k⭐.

## Repo de referencia

- **GitHub:** `github.com/MobilityData/awesome-transit`
- **Lenguaje:** Markdown (awesome list)
- **Licencia:** MIT
- **Mantenedor:** MobilityData (fundación open-source de transporte)

## Contenido

La lista incluye:

1. **Estándares:** GTFS, GTFS-RT, NeTEx, SIRI, TransXChange
2. **APIs:** APIs de transporte público por país/region
3. **Datasets:** Feeds GTFS de todo el mundo
4. **Herramientas:** Editores, validadores, conversores
5. **Plataformas:** Motor de routing, trip planners
6. **Librerías:** node-gtfs, gtfs-router, etc.
7. **Comunidad:** Foros, eventos, grupos de trabajo
8. **Investigación:** Papers, tesis, proyectos académicos

## Uso

```bash
# Clonar para referencia
git clone https://github.com/MobilityData/awesome-transit.git

# Explorar categorías
cat awesome-transit/README.md | grep -A 20 "## GTFS"
```

## Integración con Mastermind

- Fuente de referencia para `gtfs-to-netex-conversion`
- Complementa `transit-data-pipelines` con recursos externos
- Ideal para `opentripplanner-otp` — encontrar feeds GTFS
- Referencia para `routing-isochrones` — APIs de transporte

## Pitfalls

- **No es código:** Es una lista de recursos, no una herramienta ejecutable
- **Mantenimiento:** Depende de contribuciones de la comunidad
- **Cobertura:** Mejor para Europa/USA que para Latinoamérica
