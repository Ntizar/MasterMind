# OneBusAway GTFS Realtime Visualizer

## Qué es

Visualizador de GTFS Realtime de OneBusAway para tracking de transporte público en tiempo real:
- **GTFS-RT** — consume feeds de posición en tiempo real
- **Vehicle tracking** — muestra vehículos en mapa
- **Trip updates** — muestra actualizaciones de viajes
- **Open source** — parte del ecosistema OneBusAway

## Instalación

```bash
git clone https://github.com/OneBusAway/onebusaway-gtfs-realtime-visualizer.git
cd onebusaway-gtfs-realtime-visualizer
# Requiere servidor backend para servir datos GTFS-RT
```

## Casos de uso para David

- **Realtime tracking** — visualizar vehículos en tiempo real
- **GTFS-RT integration** — consumir feeds de posición
- **Dashboard** — integrar en dashboards de transporte
- **Learning** — entender estructura de feeds GTFS-RT

## Pitfalls

- Requiere feed GTFS-RT válido (no todos los sistemas lo tienen)
- Necesita backend para servir los datos
- No incluye recolección de datos — solo visualización
- Comunidad pequeña, mantenimiento limitado
