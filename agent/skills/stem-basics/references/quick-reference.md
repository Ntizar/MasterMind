# STEM Quick Reference — Fórmulas y Conceptos Clave

## Bloque 1 — Matemáticas

### Álgebra
- Ecuación 2º grado: `x = (-b ± √(b²-4ac)) / 2a`
- Factorización: `a² - b² = (a+b)(a-b)`
- Binomio Newton: `(a+b)ⁿ = Σ C(n,k)·aⁿ⁻ᵏ·bᵏ`

### Trigonometría
- Identidad fundamental: `sin²θ + cos²θ = 1`
- Ley senos: `a/sinA = b/sinB = c/sinC`
- Ley cosenos: `c² = a² + b² - 2ab·cosC`

### Cálculo
- Derivada: `d/dx [xⁿ] = n·xⁿ⁻¹`
- Integral: `∫ xⁿ dx = xⁿ⁺¹/(n+1) + C`
- Regla cadena: `d/dx [f(g(x))] = f'(g(x))·g'(x)`

## Bloque 2 — Física

### Mecánica
- 2ª Ley Newton: `F = ma`
- Energía cinética: `Ec = ½mv²`
- Trabajo: `W = F·d·cosθ`

### Electromagnetismo
- Coulomb: `F = k·q₁q₂/r²`
- Ohm: `V = I·R`
- Faraday: `ε = -dΦ/dt`

## Bloque 3 — Biología

### Genética
- ADN → ARNm → Proteína (centro dogma)
- Mendel: `Aa × Aa → 1AA : 2Aa : 1aa`

### Ecología
- Cadena trófica: Productor → Consumidor 1 → Consumidor 2 → Descomponedor
- Eficiencia ecológica: ~10% entre niveles tróficos
