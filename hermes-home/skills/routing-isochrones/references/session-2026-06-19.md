# TimeIneco — Lecciones de implementación (2026-06-19)

## 1. SHP generation in browser (pure JS)

**Problema:** No hay librería CDN fiable que genere shapefiles en el navegador.

**Solución:** Construir el binario manualmente con `ArrayBuffer` + `DataView`:

```
.shp file: header (100 bytes big-endian) + record (8 bytes header + content)
  - File header: FileCode=9994, FileLength, Version=1000, ShapeType=5 (Polygon), BBox
  - Record header: RecordNumber, ContentLength (16-bit words)
  - Record content: ShapeType=5, BBox (4 doubles), NumParts=1, NumPoints=N, Parts[0]=0, Points[N]×2 doubles

.shx file: Same header + index record (Offset=50 words, ContentLength)

.dbf file: dBase III header (32B + 2×32B field descriptors + 0x0D terminator) + record (space flag + MODO[10] + MINUTOS[3])
  - Field names padded to 11 bytes
  - Field types: 0x43='C', 0x4E='N'
  - Terminator byte: 0x0D

.prj file: WKT string for WGS84
```

**Empaquetado:** JSZip CDN (`cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js`) → `zip.file('name.shp', arrayBuffer)` → `zip.generateAsync({type:'blob'})` → descarga.

**Verificación:** QGIS y ArcGIS abren el .shp resultante. Para validar, importar en QGIS y comprobar que el polígono aparece en las coordenadas correctas.

## 2. html2canvas para captura de Leaflet maps

**Problema:** El PDF necesitaba un mapa capturado de Leaflet, no solo texto.

**Solución:**
```javascript
export async function capturarMapa(modo, minutos) {
  const container = document.getElementById('mapContainer');
  // Si modo es null, capturar todo; si no, ocultar layers no relevantes
  try {
    const canvas = await html2canvas(container, {
      useCORS: true,           // tiles CARTO requieren CORS
      scale: 2,                // 2x para calidad
      backgroundColor: '#ffffff'
    });
    return canvas.toDataURL('image/png');
  } catch(e) { return null; }
}
```

**⚠️ html2canvas no captura elementos fuera del viewport.** Si el mapa tiene `position: relative` y está en un sidebar scrollable, asegurar que esté en el viewport antes de capturar. Para el PDF, el mapa está en el sidebar visible así que funciona.

**⚠️ Tiles deben permitir CORS.** CARTO light_all (`https://{s}.basemaps.cartocdn.com/light_all/{z}/{x}/{y}{r}.png`) lo permite. OpenStreetMap tile servers también.

## 3. NAP city detection (transporte público)

**Patrón:** Catálogo de operadores por ciudad, detectada desde `display_name` de la geocodificación:

```javascript
const EMPRESAS = {
  madrid: [
    { nombre: 'EMT Madrid', modo: 'bus', lineas: 217 },
    { nombre: 'Metro de Madrid', modo: 'metro', lineas: 13 },
    ...
  ],
  barcelona: [ ... ],
  ...
};

function detectarCiudad(displayName) {
  const d = displayName.toLowerCase();
  for (const [ciudad, empresas] of Object.entries(EMPRESAS)) {
    if (d.includes(ciudad)) return { ciudad, empresas };
  }
  return null;
}
```

**Cobertura actual:** Madrid, Barcelona, Sevilla, Valencia, Bilbao, Zaragoza, Málaga, Gijón, Oviedo. Extensible.
