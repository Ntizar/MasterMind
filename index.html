Para qué sirve

Un asistente que recuerda, decide y mejora

Mastermind no es un chatbot: es un sistema operativo para tu IA personal. Tú das la intención; él busca el conocimiento correcto, ejecuta con especialistas y guarda lo aprendido para la siguiente vez.

◈

Automatiza tus flujos

Crons programados que exploran, informan y mantienen el sistema solos: scouting nocturno de repositorios, informes semanales, chequeos de salud diarios.

◈

Construye contigo

Dashboards, visores de mapas, informes, pipelines de datos: cada proyecto alimenta skills reutilizables. Lo que aprende una vez, lo aplica siempre.

◈

Nunca empieza de cero

Tres capas de memoria: preferencias y datos personales, procedimientos como skills, e historial completo de sesiones recuperable por búsqueda.

Arquitectura

Un orquestador, muchos especialistas

Nada de cadenas de agentes genéricos: cada skill se especializa en un dominio y Mastermind decide quién ejecuta. GitHub es la fuente de verdad, sin dependencias externas.

Capacidades

Lo que el sistema aporta

◈

Búsqueda semántica de skills

ChromaDB + qwen3-embedding: pides «analiza este PDF denso» y encuentra el skill, sin memorizar nombres.

◈

Human loop en cambios críticos

Planificar → esperar aprobación → implementar → sintetizar. Diffs siempre visibles, nunca commit sin mostrar cambios.

◈

Aprendizaje continuo

Cada sesión alimenta memoria, notas y skills nuevos. El sistema mejora con el uso, no se degrada.

Flujo

De la pregunta al resultado, con control

Flujo continuo de tareas → skills → resultados

  1. Consulta — ChromaDB recupera los skills relevantes por significado (score > 0,25).
  2. Clasificación — nivel de ejecución 1-4 según complejidad y coste.
  3. Delegación — subagentes especializados ejecutan en paralelo cuando aporta.
  4. Verificación — resultado comprobado contra la realidad antes de reportar.
  5. Aprendizaje — skill, nota o memoria nueva si la sesión enseñó algo.
Human loop en cada fase Los cambios críticos (>5 archivos, arquitectura, deploy) se planifican, se presentan y esperan aprobación explícita antes de ejecutarse. Diffs siempre visibles, rollback siempre disponible.
