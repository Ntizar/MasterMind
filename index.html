Características

¿Cómo funciona?

🧠

Orquestación Inteligente

Koldo clasifica cada tarea por dominio y complejidad. Decide si la resuelve directo, delega a 1 subagente o lanza varios en paralelo.

⚡

143 Skills Especializados

Software, GitHub, Frontend, Backend, Infra, DevOps, Data Science, Creative. Cada skill tiene conocimiento profundo de su dominio.

💾

Memoria Persistente

3 capas de memoria: preferencias con memory, procedimientos con skills, historial con session_search. Nunca empiezas desde cero.

🚀

Deploy en la Nube

MicroVM en NaN.builders con 1vCPU/2GB. Acceso vía Telegram y WebUI. Modelo qwen3.6 a ~$0.50/1M tokens.

El flujo en acción

Tu das una tarea → Koldo clasifica → Carga skills del dominio → Ejecuta y verifica → Aprende para la próxima
Inicio rápido

1

Clona el repositorio

git clone https://github.com/Ntizar/NtizarBrainMasterMind.git
2

cd NtizarBrainMasterMind hermes . # o tu IDE preferido
3

12 Reglas

Derivadas de 13 ciclos de uso real

  1. Un orquestador, muchos especialistas — Koldo clasifica y delega, los skills ejecutan
  2. Skills bajo demanda por dominio — solo cargo los del dominio relevante
  3. Memoria persistente — memory + session_search entre sesiones
  4. GitHub como fuente de verdad — Markdown plano, sin dependencias externas
  5. NUNCA borrar del repo Koldo — solo crear o modificar
  6. Notas significativas → notes/YYYY-MM-DD-titulo.md
  7. Skills nuevos → /hermes-home/skills/
  8. Cada aprendizaje importante → commit al repo
  9. No crear secrets en notes/commits/chat
  10. SOUL.md es la fuente de verdad de la identidad del sistema
  11. TODO en castellano — NUNCA inglés en repos, scripts, informes
  12. Human loop en cambios críticos — presentar diffs y esperar aprobación ✅
