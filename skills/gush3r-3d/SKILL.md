# GUSH3R — Visualización 3D Geoespacial

## Qué es

GUSH3R es una herramienta de visualización 3D orientada a datos geoespaciales españoles:
- **3D visualization** — renderizado 3D de datos geográficos
- **Spain-focused** — datos y proyecciones específicas de España
- **Python-based** — fácil integración con pandas/geopandas
- **Interactive** — visualización interactiva en navegador

## Instalación

```bash
git clone https://github.com/abkeito/GUSH3R.git
cd GUSH3R
pip install -e .
```

## Casos de uso para David

- **Visualización 3D** — terrenos y edificios españoles
- **Integración** — combinar con Three.js para web
- **GIS analysis** — análisis espacial en 3D
- **PNT** — integración con Plan Nacional de Topografía

## Pitfalls

- Comunidad pequeña, documentación limitada
- Depende de librerías específicas de Python
- Datos geoespaciales españoles pueden ser pesados
- No es un motor de renderizado completo — más bien una herramienta de visualización
