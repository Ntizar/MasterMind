# Minimap.js — Minimapas Interactivos

## Qué es

Minimap.js es una librería ligera para crear minimapas interactivos:
- **Lightweight** — muy pequeño, fácil de integrar
- **Interactive** — zoom, pan, markers
- **Vanilla JS** — sin dependencias
- **Customizable** — estilos y comportamientos custom

## Instalación

```bash
# Via npm
npm install minimaps-js

# O CDN
<script src="https://cdn.example.com/minimaps.min.js"></script>
```

## Casos de uso para David

- **Dashboard maps** — minimapas en dashboards de transporte
- **Navigation UI** — minimapas para apps de navegación
- **Multi-map** — mapas principales + minimapas contextuales
- **Lightweight alternative** — alternativa ligera a Leaflet/Mapbox para casos simples

## Pitfalls

- No es un motor de mapas completo — solo minimapas
- Funcionalidad limitada comparado con Leaflet/Mapbox
- No incluye tile serving — necesita tiles externos
- Comunidad pequeña
