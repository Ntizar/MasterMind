# Three.js Awesome Graphics Agent Skills

## Qué es

Colección de skills/prompts para usar agentes IA (como Hermes) para generar gráficos 3D con Three.js:
- **Agent prompts** — prompts optimizados para generar código Three.js
- **Graphics patterns** — patrones de gráficos 3D comunes
- **Voice AI integration** — combinar 3D con voice AI
- **Geospatial 3D** — patrones específicos para visualización geoespacial

## Instalación

```bash
git clone https://github.com/scottstts/Threejs-Awesome-Graphics-Agent-Skills.git
# Usar como referencia para prompts de IA
```

- Es una colección de prompts, no una librería ejecutable
- Los prompts pueden necesitar adaptación para cada caso
- No incluye código de producción — solo ejemplos
- Depende de la calidad del modelo IA
